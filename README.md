# 📊 Sales Performance Dashboard (Power BI)

## 🚀 Project Overview

This project focuses on analyzing retail sales data and building an interactive dashboard using Power BI to derive business insights.

---

## 📁 Dataset

* Source: Superstore Dataset (Kaggle)
* Contains sales, customer, product, and regional data

---

## 🛠 Tools Used

* Power BI (Dashboard)
* Python (Pandas, Matplotlib)
* Excel (Data Cleaning)

---

## 📊 Dashboard Features

* Monthly Sales Trend
* Sales by Category
* Regional Performance Analysis
* Top Products Identification
* Interactive Filters (Region, Category, Year)

---

## 💡 Key Insights

* West region generates the highest sales
* Technology category contributes the most revenue
* Sales increase towards year-end
* Few products contribute majority of sales

## 📌 Conclusion

This project demonstrates skills in data cleaning, exploratory data analysis, and building interactive dashboards for business decision-making.
